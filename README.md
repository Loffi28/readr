# Readr — читалка с переводом

Бесплатная читалка для изучения языков в духе LingQ и Lute v3. Работает на ноутбуке с Windows, на iPhone, на Android: это веб-приложение, которое ставится как обычное. Тексты, словарь и прогресс хранятся только на вашем устройстве.

## Что умеет

**Добавление текстов**
- вставить текст из буфера;
- файлы: PDF (сканы распознаются автоматически), EPUB, FB2 (и FB2 в zip), DOCX, TXT, Markdown, субтитры SRT/VTT, HTML;
- фото страницы с камеры или из галереи, можно несколько страниц сразу — текст распознаётся прямо на устройстве;
- статья по ссылке;
- перетаскивание файла в окно, а в Windows — «Открыть с помощью → Readr».

**Чтение**
- незнакомые слова подсвечены голубым, изучаемые — персиковым, светлеющим по мере изучения (статусы 1–4), знакомые без подсветки;
- нажали на слово — перевод, варианты по частям речи, предложение-контекст и его перевод, ссылки на Reverso Context, Викисловарь, Google Картинки;
- свой перевод и заметка к слову;
- фразы: протяните мышью по нескольким словам, Shift+клик или кнопки «+ слово» на телефоне;
- параллельный перевод: абзац оригинала рядом с переводом (на телефоне — под ним);
- озвучка слова, предложения и всей страницы с подсветкой текущего предложения — живым голосом Google или голосом системы без интернета;
- «Перелистнул — значит знаю»: слова, на которые вы не нажали, становятся знакомыми (отключается в настройках);
- в библиотеке видно, сколько процентов новых слов в каждом тексте.

**Словарь и повторение**
- поиск, фильтры (изучаю, фразы, знаю, игнор), правка;
- экспорт в CSV и в Anki, импорт из CSV (LingQ, Lute, Anki);
- карточки с интервальным повторением: «Не помню / С трудом / Помню / Легко», в обе стороны.

**Прогресс**: число знакомых слов, цель на день, дни подряд, график за 14 дней.

## Горячие клавиши в читалке

| Клавиша | Действие |
|---|---|
| 1–4 | статус слова |
| 5 или K | знаю |
| I | игнорировать |
| ← → | соседнее слово (без выделения — страница) |
| Shift + ← → | расширить фразу |
| P | произнести |
| T | перевести предложение |
| Esc | закрыть панель |

## Установка

**iPhone**: откройте адрес приложения в Safari → «Поделиться» → «На экран Домой».
**Windows**: в Edge или Chrome значок установки справа в адресной строке.

Данные на телефоне и ноутбуке отдельные. Чтобы перенести их: «Настройки → Сохранить копию» на одном устройстве и «Загрузить копию» на другом, словари объединятся.

## Запуск локально

```
python -m http.server 5178 --directory app
```

и откройте http://localhost:5178.

## ИИ-помощник (по желанию)

«Настройки → ИИ-помощник»: Claude (по умолчанию Haiku 5.5 — самый дешёвый), OpenRouter (есть бесплатные модели), Google Gemini или свой сервер, совместимый с OpenAI (например, Ollama). С ключом:
- слово переводится по смыслу в конкретном предложении, плюс словарная форма и короткая заметка о нюансах;
- предложения и абзацы (и параллельный перевод) переводятся моделью, при сбое — через Google;
- текст с фото и сканов очищается от ошибок распознавания.

Ключ хранится только на устройстве и не попадает в резервную копию.

## Откуда перевод

Бесплатные сервисы без ключей: публичный эндпоинт Google Переводчика, MyMemory как запасной, или ваш сервер LibreTranslate. Распознавание текста — Tesseract.js, PDF — pdf.js, EPUB — JSZip, DOCX — mammoth. Всё грузится с jsDelivr и кэшируется для работы офлайн.
